 # AI-SOC — 4-Node Distributed Security Operations Center

  > Status: under construction · started 2026-05-17

  An AI-augmented Security Operations Center distributed across 3 Windows hosts
  and 1 Linux NIDS sensor (WSL2 Ubuntu). Combines Wazuh SIEM, TheHive/Cortex/Shuffle
  SOAR, an 8-microservice AI intelligence layer (ML + RAG + local LLM via Ollama),
  Suricata + Zeek network detection, and full-stack observability.
